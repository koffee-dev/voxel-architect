# 🧱 Voxel Architect

**Prompt-to-voxel structure generator** — type a prompt like *"cozy cottage with chimney"*,
get voxel buildings generated by a constraint-based (WFC-style) generator, and save the
good ones to a named library for later composition.

**Phase 1** (this repo state): single-structure generation, 4-variant candidate strip,
manual parameter controls, and a localStorage-backed structure library.
**Phase 2** (planned): `@`-mention composition ("generate a @cave system that
interconnects and is traversable"), full structure editing, and Jev-powered
prompt understanding + candidate curation. The composer is intentionally
domain-agnostic — it works for cave systems as naturally as for anything else.

## Run it

No build step — it's a pure static site.

```bash
cd voxel-architect
python3 -m http.server 8000
# open http://localhost:8000
```

> The 3D viewport loads Three.js from the jsDelivr CDN, so you need internet
> access on first load. Everything else is local.

To publish: push to GitHub and enable **GitHub Pages** (Settings → Pages →
Deploy from branch → `main` / root). The live site is served straight from
these files.

## Controls

- **Prompt** — describe the structure. Keywords steer the generator:
  `tower`, `castle`, `cottage`, `cabin`, `mansion`, `shop`, `apartment`,
  `temple`, `bridge`, `house`. (Keyword stub — Jev takes over in Phase 2.)
- **⚡ Generate** — builds 4 variants. New prompt text re-seeds the sliders
  via the keyword map; tweaking sliders then re-generating uses your values.
  `Ctrl+Enter` in the prompt box also generates.
- **Parameters** — width, depth, stories, roof style (gable/hip/flat),
  window density, chimney, symmetry, crenellation, pillars.
- **Viewport** — drag to orbit, scroll to zoom, right-drag to pan.
- **Candidate strip** — click a variant to inspect it in the main view.
- **💾 Save to library** — names the selected variant (defaults from your
  prompt) and stores it with a thumbnail.
- **Library** — click a saved structure to reload it (regenerated
  deterministically from its seed + params). ✏️ renames, 🗑 deletes.
  Stored in `localStorage` under `voxel-architect.library.v1`.

## Tech notes

- Voxels render as one `THREE.InstancedMesh` per block type (12 types), so
  even large structures are a handful of draw calls.
- Generation is fully seeded (`mulberry32`): the library stores
  `{params, seed, tilesetVersion}` — never the grid — and regenerates on load.
- `wfc.js` has no DOM dependencies and can be unit-tested in Node.
